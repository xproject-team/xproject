## Before printing

Replace these placeholders with actual phone numbers:

- `_[pre-filled by manager]_` (bartender sheet) — manager phone numbers
- `_[pre-filled by owner]_` (manager + warehouse sheets) — owner + Slesh contacts
- `_[your number]_` (owner sheet) — Hesam's direct line
- `_[Slesh contact]_` (owner sheet) — Slesh support number

A search/replace pass in any text editor will fill them in fast.

## Pre-event training session

Plan a 30-minute group session 1-2 days before Sundance where:

1. Each role reads their own sheet (10 min)
2. Owner walks through the role matrix with everyone in the room (10 min)
3. Practice round: each role does ONE scan + ONE chat message on the staging
   tablet (10 min)

After this session, paper copies of the relevant sheet stay at the
operator's station for the whole event.
